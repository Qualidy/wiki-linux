    Linux Evolution und beliebte Betriebssysteme¶

    1. Einstieg: Was ist ein Betriebssystem?¶

    Ein Betriebssystem ist die grundlegende Software eines Computers.

    Es verwaltet zum Beispiel:

    • Hardware
    • Programme
    • Dateien
    • Benutzerkonten
    • Speicher
    • Netzwerkverbindungen
    • Sicherheit

    Ohne Betriebssystem wäre ein Computer für normale Nutzer kaum bedienbar.

    Einfach gesagt

    Das Betriebssystem ist die Vermittlung zwischen Mensch, Programmen und Hardware.

    2. Bekannte Betriebssysteme¶

    Heute gibt es viele verschiedene Betriebssysteme.

    Betriebssystem Typischer Einsatz
    Windows PCs, Laptops, Unternehmen, Gaming
    macOS Apple-Computer, Kreativbranche, Entwicklung
    Linux Server, Entwicklung, Cloud, Embedded Systems, Desktop
    Android Smartphones, Tablets, Smart-TVs
    iOS iPhones
    iPadOS iPads
    ChromeOS Chromebooks, Schulen, einfache Arbeitsplätze

    3. Kurzer Überblick: Windows¶

    Windows ist eines der bekanntesten Desktop-Betriebssysteme.

    Es wird häufig genutzt für:

    • Büroarbeit
    • Gaming
    • Unternehmenssoftware
    • Schulen und Verwaltungen
    • private Computer

    Vorteile¶

    • sehr weit verbreitet
    • viele Programme verfügbar
    • gute Unterstützung für Spiele
    • viele Treiber und Hardware-Unterstützung
    • für viele Nutzer vertraut

    Nachteile¶

    • kostenpflichtige Lizenz
    • stärker von Microsoft abhängig
    • häufiges Ziel von Schadsoftware
    • weniger offen als Linux

    4. Kurzer Überblick: macOS¶

    macOS ist das Betriebssystem für Apple-Computer.

    Es wird häufig genutzt für:

    • Design
    • Medienproduktion
    • Softwareentwicklung
    • Office-Arbeit
    • kreative Berufe

    Vorteile¶

    • stabile Benutzeroberfläche
    • gute Integration mit Apple-Geräten
    • beliebt bei Entwicklern und Kreativen
    • basiert technisch auf Unix

    Nachteile¶

    • läuft offiziell nur auf Apple-Hardware
    • Apple-Geräte sind oft teuer
    • weniger flexibel als Linux
    • weniger Gaming-Auswahl als Windows

    5. Kurzer Überblick: Linux¶

    Linux ist ein freies und quelloffenes Betriebssystem beziehungsweise genauer gesagt ein Betriebssystem-Kernel.

    Im Alltag meint man mit „Linux“ meistens eine komplette Linux-Distribution.

    Beispiele:

    • Ubuntu
    • Debian
    • Fedora
    • Linux Mint
    • Arch Linux
    • openSUSE
    • Kali Linux
    • Raspberry Pi OS

    Wichtig

    Streng genommen ist Linux nur der Kernel.
    Eine nutzbare Linux-Version besteht aus Kernel, Systemprogrammen, Paketverwaltung, Benutzeroberfläche und weiteren Tools.

    6. Was ist ein Kernel?¶

    Der Kernel ist der zentrale Kern eines Betriebssystems.

    Er kümmert sich um die Kommunikation zwischen Software und Hardware.

    Der Kernel verwaltet zum Beispiel:

    • Prozessor
    • Arbeitsspeicher
    • Festplatten
    • USB-Geräte
    • Netzwerk
    • Prozesse
    • Rechte

    Merksatz

    Der Kernel ist das Herz des Betriebssystems.

    7. Was ist eine Linux-Distribution?¶

    Eine Linux-Distribution ist ein komplettes Betriebssystem, das den Linux-Kernel verwendet.

    Eine Distribution enthält meistens:

    • Linux-Kernel
    • Paketmanager
    • Systemwerkzeuge
    • grafische Oberfläche
    • Standardprogramme
    • Update-System
    • Sicherheitskonfigurationen

    Beispiel¶

    Ubuntu ist eine Linux-Distribution.

    Ubuntu enthält unter anderem:

    • den Linux-Kernel
    • den Paketmanager apt
    • eine grafische Benutzeroberfläche
    • Programme wie Dateimanager, Terminal und Browser
    • Update-Verwaltung

    8. Die Evolution von Linux¶

    Vor Linux: Unix¶

    Bevor Linux entstand, gab es bereits Unix.

    Unix wurde ab Ende der 1960er-Jahre entwickelt und war besonders in Universitäten, Forschung und Unternehmen verbreitet.

    Viele moderne Betriebssysteme wurden stark von Unix beeinflusst.

    Dazu gehören:

    • Linux
    • macOS
    • BSD-Systeme
    • Android

    1980er-Jahre: Freie Software und GNU¶

    In den 1980er-Jahren entstand die Bewegung für freie Software.

    Das Ziel war, Software so bereitzustellen, dass Nutzer sie:

    • verwenden
    • verstehen
    • verändern
    • weitergeben

    Ein wichtiges Projekt war das GNU-Projekt.

    GNU entwickelte viele freie Systemwerkzeuge, aber es fehlte lange ein eigener Kernel.

    1991: Linus Torvalds startet Linux¶

    Im Jahr 1991 begann Linus Torvalds mit der Entwicklung eines eigenen Kernels.

    Dieser Kernel wurde später als Linux bekannt.

    Am Anfang war Linux ein Hobbyprojekt.

    Später arbeiteten immer mehr Entwickler aus der ganzen Welt daran mit.

    1990er-Jahre: Erste Distributionen¶

    In den 1990er-Jahren entstanden erste Linux-Distributionen.

    Dazu gehörten zum Beispiel:

    • Slackware
    • Debian
    • Red Hat Linux
    • SUSE Linux

    Diese Distributionen machten Linux für mehr Menschen nutzbar, weil sie Kernel, Tools und Installationsprogramme bündelten.

    2000er-Jahre: Linux auf Servern¶

    In den 2000er-Jahren wurde Linux besonders auf Servern immer wichtiger.

    Gründe dafür waren:

    • Stabilität
    • Sicherheit
    • freie Verfügbarkeit
    • gute Netzwerkfunktionen
    • starke Community
    • niedrige Lizenzkosten

    Linux wurde wichtig für:

    • Webserver
    • Datenbanken
    • E-Mail-Server
    • Unternehmensserver
    • Rechenzentren

    2010er-Jahre: Cloud, Android und Container¶

    In den 2010er-Jahren wurde Linux noch bedeutender.

    Wichtige Entwicklungen:

    • Cloud-Computing
    • Docker und Container
    • Kubernetes
    • Android
    • Raspberry Pi
    • DevOps-Kultur

    Linux wurde zur Grundlage vieler moderner IT-Systeme.

    Praxisbezug

    Viele Webseiten, Apps, Cloud-Dienste und Server laufen heute auf Linux-Systemen.

    Heute: Linux überall¶

    Linux läuft heute nicht nur auf klassischen Computern.

    Linux steckt auch in:

    • Servern
    • Smartphones
    • Routern
    • Smart-TVs
    • Autos
    • Industrieanlagen
    • Supercomputern
    • Cloud-Plattformen
    • Docker-Containern
    • Raspberry Pi
    • IoT-Geräten

    9. Warum ist Linux so beliebt?¶

    Linux ist besonders beliebt, weil es:

    • kostenlos nutzbar ist
    • Open Source ist
    • stabil läuft
    • flexibel anpassbar ist
    • auf vielen Geräten funktioniert
    • gut für Server geeignet ist
    • in der Cloud stark verbreitet ist
    • viele Entwicklerwerkzeuge bietet
    • eine große Community hat

    10. Linux im Alltag¶

    Viele Menschen nutzen Linux, ohne es direkt zu merken.

    Beispiele:

    • Webseiten werden oft von Linux-Servern ausgeliefert
    • Android basiert auf dem Linux-Kernel
    • viele Router nutzen Linux
    • Smart-TVs nutzen oft Linux
    • Cloud-Dienste laufen häufig auf Linux
    • Docker-Container laufen meist mit Linux-Basis

    Frage an die Gruppe

    Wo begegnet euch Linux im Alltag, ohne dass ihr es direkt seht?

    11. Beliebte Linux-Distributionen¶

    Distribution Typischer Einsatz
    Ubuntu Einsteiger, Desktop, Server, Entwicklung
    Debian Server, stabile Systeme, Grundlage vieler anderer Distributionen
    Linux Mint Einsteiger, Desktop, Windows-Umsteiger
    Fedora moderne Technologien, Entwickler
    Arch Linux fortgeschrittene Nutzer, maximale Kontrolle
    openSUSE Desktop, Server, Unternehmen
    Kali Linux IT-Sicherheit, Penetration Testing
    Raspberry Pi OS Raspberry Pi, Bildung, Bastelprojekte
    Red Hat Enterprise Linux Unternehmen, professionelle Server

    12. Ubuntu¶

    Ubuntu ist eine der bekanntesten Linux-Distributionen.

    Sie ist beliebt bei:

    • Einsteigern
    • Entwicklern
    • Schulen
    • Servern
    • Cloud-Systemen

    Vorteile¶

    • einfache Installation
    • große Community
    • viele Anleitungen im Internet
    • gute Hardware-Unterstützung
    • regelmäßige Updates

    Typischer Einsatz¶

    • Desktop-PC
    • Webentwicklung
    • Linux-Lernen
    • Server
    • Cloud

    13. Debian¶

    Debian ist eine sehr stabile und traditionsreiche Distribution.

    Viele andere Distributionen basieren auf Debian, zum Beispiel Ubuntu.

    Vorteile¶

    • sehr stabil
    • große Paket-Auswahl
    • frei und communitygetrieben
    • beliebt auf Servern

    Typischer Einsatz¶

    • Server
    • stabile Desktop-Systeme
    • Grundlage für andere Distributionen

    16. Arch Linux¶

    Arch Linux richtet sich eher an fortgeschrittene Nutzer.

    Es wird stark selbst konfiguriert.

    Vorteile¶

    • sehr flexibel
    • sehr aktuell
    • gute Dokumentation im Arch Wiki
    • Nutzer lernt viel über Linux

    Nachteile¶

    • nicht ideal für Anfänger
    • Einrichtung benötigt mehr Wissen
    • mehr Eigenverantwortung bei Updates

    Typischer Einsatz¶

    • Lernsystem
    • Power-User-Desktop
    • stark angepasste Systeme

    17. Kali Linux¶

    Kali Linux ist eine Spezialdistribution für IT-Sicherheit.

    Sie enthält viele Werkzeuge für:

    • Penetration Testing
    • Sicherheitsanalysen
    • Netzwerkanalysen
    • Forensik
    • Schulungen im Security-Bereich

    Wichtig

    Kali Linux ist kein normales Einsteiger-Linux für Alltag und Büroarbeit.
    Es ist ein Spezialwerkzeug für IT-Sicherheit und sollte verantwortungsvoll eingesetzt werden.

    18. Red Hat, Rocky Linux und AlmaLinux¶

    Red Hat Enterprise Linux, kurz RHEL, ist eine kommerzielle Linux-Distribution für Unternehmen.

    Sie wird genutzt für:

    • Server
    • Rechenzentren
    • Unternehmenssoftware
    • professionelle IT-Infrastruktur

    Rocky Linux und AlmaLinux sind beliebte Alternativen im Enterprise-Umfeld.

    Typischer Einsatz¶

    • Unternehmensserver
    • produktive Systeme
    • langfristig stabile Plattformen

    19. Vergleich: Windows, macOS und Linux¶

    Thema Windows macOS Linux
    Hersteller Microsoft Apple Community / verschiedene Anbieter
    Quellcode größtenteils geschlossen größtenteils geschlossen offen
    Kosten meist kostenpflichtig mit Apple-Hardware meist kostenlos
    Gaming sehr stark mittel besser geworden, aber nicht wie Windows
    Server möglich selten sehr stark
    Anpassbarkeit mittel eher gering sehr hoch
    Einsteigerfreundlichkeit hoch hoch je nach Distribution
    Updates zentral über Microsoft zentral über Apple je nach Distribution
    Hardware-Auswahl sehr groß Apple-Hardware sehr groß, aber Treiber prüfen

    20. Wann welches Betriebssystem?¶

    Windows eignet sich gut für:¶

    • Gaming
    • Microsoft-Office-Umgebung
    • viele Unternehmensprogramme
    • Nutzer, die eine vertraute Oberfläche wollen

    macOS eignet sich gut für:¶

    • Apple-Ökosystem
    • Design und Medien
    • Softwareentwicklung
    • Nutzer, die stabile Hardware-Software-Integration möchten

    Linux eignet sich gut für:¶

    • Server
    • Programmierung
    • Cloud
    • Datenschutzbewusste Nutzer
    • ältere Computer
    • technische Lernumgebungen
    • Automatisierung
    • DevOps

    • Prozesse prüfen
    • Netzwerke testen
    • Automatisierung mit Skripten
